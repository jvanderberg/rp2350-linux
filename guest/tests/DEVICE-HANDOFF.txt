Intent/context:
The user controls emulator/interpreter/translator and guest kernel sources. They wanted native compression/encryption hooks, real SSH as a test, and specifically CONNECTION-ONLY benchmarking. Native means crypto runs directly in host/emulator firmware, outside guest instruction translation. QEMU still emulates the physical RV32 CPU. Implemented:

FIDs 0..12 under SBI EID 0x0a000001. Bounded physical input/output/parameter ranges, no overlapping output with inputs, no MMIO/readonly output. MAX_BUFFER=32768, MAX_PARAMS=4096. Latest stack fixes:
- rvaccel/src/workspace.rs: per-CPU caller-owned workspace, 53,248 bytes on RV32. Includes 28,620-byte KEM scratch, 24 KiB private execution stack, counters/alignment. init_at initializes reserved memory in place without a giant return temporary. Exclusive mutable borrowing; no hidden shared workspace/global lock. RV32 assembly trampoline preserves ABI and switches from normal control stack. Stack painted, high-water measured per operation; 256-byte low-water guard checked; whole execution stack erased after calls. Guard is diagnostic, NOT hardware overflow prevention. Native release tests require <=20 KiB usage, giving >=4 KiB margin in the 24 KiB stack.
- vendor/sntrup761 0.4.0 has explicit borrowed scratch for scalar reciprocal, product, sampling, encoding. Public *_with_workspace methods erase scratch. Arithmetic/serialization/sampling/implicit rejection unchanged. PROVENANCE records modifications. 16 seeded transcript hashes match the untouched upstream crate. Independent RFC/IETF vectors also pass.
- asymmetric.rs operation functions have separate frames so small primitives do not inherit large temporary storage.
- Cpu::set_native_workspace transfers exclusive ownership of a workspace. Bare-metal firmware without provisioning reports extension unavailable even if rvcore/pv-buffers was enabled. Hosted fallback convenience run still uses caller stack; small-stack firmware MUST use Workspace::run.
- QEMU frontend --features pv-buffers reserves separate translator/reference workspaces; host frontend reserves one. scripts/virt.sh translates old rvcore/pv-buffers feature spelling to frontend pv-buffers.
- Pico shell --features pv-buffers reserves the TOP 64 KiB OF PSRAM, outside guest RAM and optional translator backing store. Compile-time size assertion and guest header RAM_MAX validation.
