#   name TEXT       shown in the room (start it with a capital)
#   room ROOMID     where it starts and respawns
#   desc TEXT       shown for "look ID"
#   say TEXT        repeatable; picked at random when it talks
#   hp N            0 or missing = cannot be attacked
#   damage N        hits for 1..N

#   want ITEMID     "give" it this to complete its quest
#   reward TEXT     what it says then
#   gives ITEMID    what it hands over then
